Pibank

Pichincha Banking App

A digital banking app for Spain, built with SwiftUI and engineered for a fast, secure, and scalable user experience. Currently in active development, the app will be released to production soon. Leveraging an MVVM architecture and a dedicated use-case layer to handle all business logic, the app offers:

Real-time balance and transaction overview, with automatic updates and customizable push notifications. Immediate and scheduled transfers, including SEPA and instant payments, featuring pre-validation and step-by-step feedback. Card management (block, unblock, and limit controls) plus spending insights through interactive charts. Biometric authentication (Face ID / Touch ID) and end-to-end encryption for maximum security. All workflows are covered by unit and integration tests, ensuring high coverage and reliability as the code evolves. Tests are organized around use cases to validate each business scenario independently, while SwiftUI views are verified with snapshot testing and data mocks.

This project highlights expertise in:

Native iOS development with SwiftUI and Combine. Solid architectural patterns such as MVVM and Clean Architecture (use cases). Designing and implementing a comprehensive testing strategy (unit tests, snapshot tests, and mocks). Focus on user experience, accessibility, and code scalability.
